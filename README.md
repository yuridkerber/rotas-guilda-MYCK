# Rotas Guilda MYCK

> Projeto acadêmico desenvolvido na disciplina de **Engenharia de Software I**, com foco na aplicação prática de conceitos de desenvolvimento de software, organização de equipe e utilização de ferramentas de versionamento.

## 📌 Sobre o projeto

O **Rotas Guilda MYCK** é um projeto desenvolvido pela guilda MYCK como parte das atividades da disciplina de Engenharia de Software I.

O projeto tem como objetivo proporcionar experiência prática com o ciclo de desenvolvimento de software, desde o planejamento e levantamento de requisitos até a implementação, documentação e evolução da aplicação.

Além do propósito acadêmico, o projeto será desenvolvido seguindo boas práticas de organização e colaboração, podendo também compor o portfólio dos integrantes da equipe.

## 🎯 Objetivos

- Aplicar conceitos estudados em Engenharia de Software.
- Praticar desenvolvimento colaborativo.
- Utilizar Git e GitHub para controle de versão.
- Aprender e aplicar boas práticas de organização de projetos.
- Desenvolver uma aplicação funcional e documentada.
- Registrar a evolução do projeto ao longo do desenvolvimento.

## 📋 Desenvolvimento

O projeto será desenvolvido de forma incremental, utilizando práticas de organização e versionamento para acompanhar sua evolução.

### Etapas previstas

1. Levantamento e definição do problema
2. Levantamento de requisitos
3. Planejamento da solução
4. Modelagem do sistema
5. Desenvolvimento
6. Testes
7. Documentação
8. Apresentação e avaliação

## 🌿 Organização do projeto

A equipe utilizará o GitHub para gerenciamento do código, versionamento e colaboração entre os integrantes.

A organização de branches, commits, issues e pull requests será definida conforme a necessidade do projeto e as práticas apresentadas durante a disciplina.
